## Project Summary
This project designs a PostgreSQL relational database for Dream Homes NYC, a real estate agency operating across NY, NJ, and CT. The database supports office operations, client management, property records, transactions, appointments, and business intelligence dashboards.

## Repository Structure
- `sql/` — schema and analytical SQL
- `etl/` — ETL scripts
- `docs/` — ERD, dashboard notes, and data documentation
- `data/` — sample data notes and dataset links

## Main Deliverables
- Relational schema in 3NF
- ETL pipeline
- 10 analytical procedures
- Metabase dashboard support
